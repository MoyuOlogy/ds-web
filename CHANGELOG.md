# Changelog

## 1.0.0 — 2026-11-19

First public release.

- DeepSeek-web-style sidebar panel for DeepSeek Harness.
- Streaming chat, DeepThink with `low / high / max` effort.
- Server-side web search with citations.
- Files API uploads (text / rich layout / user data).
- OCR through `/v1/tools/ocr`.
- DeepSeek export import (ZIP / JSON / Markdown / folder).
- Grouped chat library with pin, rename, export and delete.
- Chinese and English UI.
